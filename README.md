# Go Kifu

Редактор партий Го: запись, разбор движком KataGo, джосеки, фусеки, библиотека партий.

## Скачать программу для Windows

**[Скачать последнюю версию](https://github.com/Weaverden/gokifu/releases/latest)**

Прямая ссылка на установщик (всегда последняя версия):
`https://github.com/Weaverden/gokifu/releases/latest/download/GoKifu-setup.exe`

Программа сама проверяет обновления и ставит их по кнопке — скачивать вручную нужно только первый раз.

## Веб-версия

**[Открыть в браузере](https://weaverden.github.io/gokifu/)**

Работает без установки, в том числе на телефоне и планшете. После первого открытия работает и без сети.

## Внимание при выкладке веб-версии

В `docs/` лежит не только собранная веб-версия, но и **страница раздачи `docs/download/`**. Порядок
публикации веба удаляет из `docs/` всё, чего нет в новой сборке (так убираются файлы `*.wasm` с
прежними именами) — каталог `download/` из этой уборки нужно ИСКЛЮЧАТЬ, иначе страница пропадёт.

Страница берёт ссылки из списка выпусков через API GitHub, поэтому после нового выпуска править её
не нужно: для ПК она ищет свежий выпуск с файлом `.exe`, для телефона — с `.apk`.

## Потоки выпусков

- `v1.0.1`, `v1.0.2`, … — настольная версия (файл `GoKifu-setup.exe` + `.sha256`);
- `android-v0.6.11`, … — приложение для телефона (файл `GoKifu-<версия>.apk` + `.sha256`).

Нумерация у них разная и не связана. Настольная версия читает НЕ «последний выпуск», а список
выпусков, и берёт первый, где есть `.exe`: иначе андроидный выпуск, оказавшись последним, ломал бы
ей проверку обновлений (проверено 28.08.2026 — так и произошло бы).

## Файлы выпусков в России не скачиваются напрямую

GitHub отдаёт приложенные к выпускам файлы с отдельного хоста `release-assets.githubusercontent.com`,
и он в России не открывается: имя разрешается, соединение не устанавливается (проверено 28.08.2026;
под VPN всё работает). Сам `github.com`, `api.github.com` и Pages при этом доступны.

Поэтому **ссылки на файлы раздаются через посредник**:

```
https://gokifu.vercel.app/api/ydisk?url=<ссылка на файл выпуска>
```

Он пропускает только ссылки вида `github.com/Weaverden/gokifu/releases/[latest/]download/…`.
Замеры через него: установщик 158 435 967 байт за 34–39 с, APK 29 048 738 байт за 7–9 с, контрольные
суммы совпали. Так же качает и настольная версия при обновлении.

**Постоянной ссылки «последняя версия» у настольной версии больше нет:** `releases/latest/download/…`
отдаёт 404, потому что последним выпуском стал андроидный. Единственный адрес, который надо
раздавать людям, — страница `https://weaverden.github.io/gokifu/download/`.
