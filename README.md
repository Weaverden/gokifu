# Go Kifu

Редактор партий Го: запись, разбор движком KataGo, джосеки, фусеки, библиотека партий.

## Скачать программу для Windows

**[Скачать последнюю версию](https://github.com/Weaverden/gokifu/releases/latest)**

Прямая ссылка на установщик (всегда последняя версия):
`https://github.com/Weaverden/gokifu/releases/latest/download/GoKifu-setup.exe`

Программа сама проверяет обновления и ставит их по кнопке — скачивать вручную нужно только первый раз.

## Веб-версия

**[Открыть в браузере](https://weaverden.github.io/gokifu/)**

Работает без установки, в том числе на телефоне и планшете. После первого открытия работает и без сети.

## Приложение для телефона

Android — в RuStore и AppGallery.
